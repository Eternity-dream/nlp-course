## 在线服务与完整规划

2026-11-15 实际 DeepSeek `deepseek-flash`、高德 Web 服务与 Exa 匿名 MCP 连通性检查成功。在线验收命令：

```sh
uv run python scripts/accept_backend_live.py --output-dir backups/acceptance/live-xian-20261115-120s --start-date 2026-12-01 --direct --provider-timeout 120
```

样例为西安 2026-12-01 至 12-03、两名成年人、全程预算 3000 元，偏好历史文化和当地美食。脚本在模型追问后补充中心城区、室内为主、单次户外不超过 60 分钟、愿意预约但尚未预约等样例条件，并通过保存要求新版本及 `resume` 继续原任务。脚本随后检查编辑、其他日期保持、重启和备份恢复。

首轮真实调用在高德候选地点查询阶段出现频率限制，任务保留为失败状态。已补充高德有限退避与共享节流：短时 QPS 错误或 HTTP 429 最多尝试三次，首次限流后同一实例的地点／路线请求至少间隔 1.1 秒；尊重 `Retry-After`，单次需等待超过 30 秒时返回可重试错误和时间。分钟级限流保留 60 秒冷却，鉴权、额度和参数错误直接返回。错误码对应关系以[高德官方说明](https://lbs.amap.com/api/webservice/guide/tools/info)核对，并加入自动回归。

安装环境代理曾返回自签名证书链，在线验收使用 `--direct` 仅为该进程设置直连并保留 TLS 校验；本机 HTTP 轮询始终直连回环地址。默认 30 秒单次调用在实际事实提取中超时，后续验收使用 `--provider-timeout 120`，项目 `.env` 保持原配置。

事实覆盖不足的具体原因：18 条提取事实的引用未同时对应地图地点名称与完整地址，6 条的时间或金额未与原文对应；这些事实保留为未知。下一轮优先改进地点与来源对应、引用提取质量及日期适用性，再核对营业时间、票价和全程预算。

使用原备份恢复到独立目录，将第一天午餐延长 5 分钟，真实模型复测成功，耗时 **54.031 秒**，结果保存为版本 3，见 [2026-11-15-live-edit-fix.json](2026-11-15-live-edit-fix.json)。误报清除，`constraint_conflicts` 为空，核验恢复为 `needs_review`；预约说明和其他日期保持一致。随后重启与再次备份／恢复也通过。18 条剩余提取事实仍为未知。
