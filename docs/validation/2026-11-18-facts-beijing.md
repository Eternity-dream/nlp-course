# 事实核实与北京行程验收（2026-11-18）

事实提取分开保存地点身份、事实数值及日期适用规则的原文。独立模型审核检查地点/馆区对应、规则解释及来源性质；程序检查引用存在、时间与金额、每周规则、跨年季节范围、日期排除和例外。过期公告、缺少日期依据及第三方信息保留待核对或估算。

新增预约事实与票种适用范围。同一地点的普通门票和联票分开处理。官网分项列出的“开放入馆时间／闭馆时间”及“6:30开园／22:00闭园”得到支持，停止入馆时间不会替代闭馆时间。恢复任务时可用已保存原文与语义审核重新计算校验结果，并保持事实 ID。

活动介绍由独立模型步骤生成，正文介绍地点或当地饮食特色，不写规划理由、预算及核验说明。餐饮采用自由用餐时段，不指定店家；页面按半小时粒度显示约略区间，隐藏具体门店地址与区域锚点事实。同一区域锚点的连续活动不再向地图查询绕行路线。
