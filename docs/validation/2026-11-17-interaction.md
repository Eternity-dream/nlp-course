# 行程输入与补充交互验收（2026-11-17）

行程表单将要求、重点和已知条件合并为“补充说明（选填）”，既有条目保存时保留原分类。预算标签直接说明门票、餐饮和当地交通口径。输入框不显示示例占位内容。

等待补充时在当前页面自动打开弹窗，日期和人数缺失时显示对应字段。回答追加到原说明，问答上下文保存在行程要求版本中，保存后继续原任务。关闭后可以重新打开，后台轮询保持已输入内容；保存失败保留输入，保存成功而继续失败时重试不重复追加回答。预算问题可直接在弹窗修改或清空预算。

普通偏好缺失时直接规划，模型追问限制为每轮最多两项；景点组合、节奏和餐饮由系统推荐，住宿位置作为参考，不追问住宿档次或是否预订。明确预算口径冲突需要澄清。
