    \textbf{\color{BrandBlue}核心摘要}\\[0.35em]
    \normalfont
    本项目面向中文自由行用户，针对目的地与日期已确定的 3--7 天中国大陆单城旅行，设计并实现了一套\textbf{单人本机部署、动态自主规划、事实可溯源、支持定点局部编辑}的旅行规划系统。系统以 React + TypeScript + Vite 构建响应式界面，以 FastAPI + Python 3.13 与 SQLite（FTS5，Schema v6）作为核心后端，通过单一 Docker Compose 容器交付；规划侧结合高德地图真实 POI 与路线、本地中文知识库检索以及 \texttt{Exa $\rightarrow$ DeepSeek $\rightarrow$ Tavily $\rightarrow$ AnySearch} 四家搜索回退链路，将行程生成、分离式事实核验与独立模型审核有机闭环。
